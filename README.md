# Block City 3D

Protótipo original de mundo aberto em 3D, feito com HTML, JavaScript e Three.js.

## Como jogar
- Clique em **Iniciar Jogo** e depois clique na cena para capturar o mouse.
- **WASD**: andar ou dirigir.
- **Mouse**: olhar ao redor.
- **E**: entrar/sair do veículo mais próximo.
- **Clique esquerdo**: quebrar um bloco destrutível no centro da tela.
- **Clique direito**: colocar um bloco na superfície apontada.
- **G**: efeito de explosão que remove blocos próximos e danifica veículos próximos.
- **Esc**: liberar o mouse/pausar.

## Publicar para jogar no navegador
1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)** e salve.
4. Aguarde o GitHub Pages publicar o site. O endereço normalmente será `https://marquesswami618-afk.github.io/block-city-3d/`.

## Observações
- Protótipo inicial: cidade de blocos, personagem original, veículos dirigíveis, colocação/remoção de blocos e efeito de explosão.
- Usa Three.js via CDN, então precisa de internet para carregar a biblioteca.
- Não inclui código, mapas, personagens, músicas ou outros arquivos proprietários de GTA V ou Minecraft.
